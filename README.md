# Tý học tiếng Anh

Ứng dụng trò chơi ôn thi giữa kỳ I tiếng Anh lớp 1 (giáo trình Power Up 1) cho Trường An, lớp 1A3.

- 31 trò chơi: từ vựng, dạng bài trong phiếu ôn tập (Task 1–7) và 10 trò luyện nói bài "My classroom".
- Hai giọng đọc thu sẵn trong trang: giọng nữ trẻ (mặc định) và giọng nam Anh – Anh, đổi trong mục "Bố mẹ".
- Tiến độ, sao và sticker được lưu trên trình duyệt của từng máy.

## Cách mở

Mở địa chỉ GitHub Pages của kho này trên Safari (iPad, iPhone) hoặc Chrome (Android), rồi chọn "Thêm vào Màn hình chính".

## Các file

| File | Vai trò |
|---|---|
| index.html | Toàn bộ ứng dụng: hình, âm thanh, trò chơi |
| sw.js | Lưu trang vào máy để chơi được khi mất mạng |
| manifest.json, icon-*.png | Biểu tượng khi thêm vào màn hình chính |
| .nojekyll | Để GitHub Pages phục vụ nguyên file, không xử lý thêm |

Hình đồ vật và file nghe Task 6 lấy từ phiếu ôn tập của nhà trường, chỉ dùng cho việc ôn tập tại nhà.
